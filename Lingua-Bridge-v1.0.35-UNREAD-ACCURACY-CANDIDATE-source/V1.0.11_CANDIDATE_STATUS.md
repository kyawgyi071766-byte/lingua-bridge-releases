# Lingua Bridge v1.0.11 — Owner/Admin Custom Apps + Signal Candidate

The public/known-good v1.0.9 production installer and Vercel production deployment are intentionally untouched.

Candidate scope:
1. Keep every existing v1.0.10 messaging-service addition.
2. Keep Signal Desktop as an official external launcher with official-download fallback.
3. Add an Owner/Admin-only Custom App Manager for reusable HTTPS web-chat/app templates.
4. Preserve custom app instances/login sessions even if the owner later deletes the reusable template.
5. No server/database migration required for this desktop-only candidate.
6. Build/install under a separate app ID and product name so testing does not replace stable Lingua Bridge.

Build:
- Open `desktop-bridge` and run `BUILD_WINDOWS_v1.0.11_ADMIN_CUSTOM_CANDIDATE.bat`.
- Or run the root helper `BUILD_WINDOWS_v1.0.11_ADMIN_CUSTOM_CANDIDATE.bat`.

Promotion gate:
- Test side-by-side with stable v1.0.9.
- Verify owner/admin sees the custom manager and normal customer accounts do not.
- Verify Telegram/WhatsApp existing behavior remains unchanged.
- Verify Signal opens official Signal Desktop.
- Verify each custom site before customer use; unknown sites use the generic DOM adapter and may need tuning.
