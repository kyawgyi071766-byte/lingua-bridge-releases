# Lingua v1.0.16 — Owner Next Steps

1. Keep stable v1.0.9 installed and keep the current Vercel production deployment unchanged.
2. Build this desktop candidate with `BUILD_WINDOWS_v1.0.16_MICROSOFT_FALLBACK_CANDIDATE.bat`.
3. Create an Azure Translator resource and obtain its key, region (if required), and endpoint.
4. Add the Microsoft values to a Vercel Preview environment only:
   - `MICROSOFT_TRANSLATOR_KEY`
   - `MICROSOFT_TRANSLATOR_REGION`
   - `MICROSOFT_TRANSLATOR_ENDPOINT=https://api.cognitive.microsofttranslator.com`
   - `TRANSLATE_PROVIDER=auto`
   - `TRANSLATE_CHAIN=deepl,microsoft,google`
5. Preview-test English <-> Myanmar/Burmese, Thai, Vietnamese, Arabic, and Hindi.
6. Force a DeepL-unsupported pair and confirm Microsoft is used.
7. Only if Google is configured, simulate/observe a Microsoft failure and confirm Google fallback.
8. Confirm failed translations preserve the original text and never auto-send a blank/incorrect replacement.
9. Promote server changes to production only after those checks pass.
10. Yandex and LibreTranslate remain intentionally deferred to the next stages.
