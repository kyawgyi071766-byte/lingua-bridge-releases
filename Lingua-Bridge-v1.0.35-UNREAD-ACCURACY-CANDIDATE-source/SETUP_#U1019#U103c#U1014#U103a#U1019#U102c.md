# Lingua — မြန်မာဘာသာ Production Setup

ဒီ version မှာ Stripe ကို customer UI ကနေဖယ်ထားပြီး **USDT → Owner Trust Wallet** ပေးချေမှုစနစ်ကို အဓိကအသုံးပြုထားပါတယ်။ Stripe source files ကို legacy အဖြစ်ထားပေမယ့် `LEGACY_STRIPE_ENABLED=false` နဲ့ default ပိတ်ထားပါတယ်။

## ၁။ Project ကို run စမ်းခြင်း

```bash
npm install
npx prisma generate
npx prisma db push
npm run dev
```

Production မတင်ခင်:

```bash
npm run verify:config
npm run audit:static
npm run build
```

## ၂။ မဖြစ်မနေထည့်ရမယ့်အချက်များ

`.env` ထဲမှာ အနည်းဆုံး ဒီအရာတွေဖြည့်ပါ။

```env
AUTH_SECRET=အရှည်ကြီး random secret
DATABASE_URL=PostgreSQL connection string
NEXT_PUBLIC_SITE_URL=https://သင့်domain.com
ADMIN_EMAIL=သင့်email

DEEPL_API_KEY=...
# သို့မဟုတ်
GOOGLE_TRANSLATE_API_KEY=...

CRYPTO_CHAIN=tron
CRYPTO_WALLET_ADDRESS=သင့် Trust Wallet public receiving address
TRONSCAN_API_KEY=
BSCSCAN_API_KEY=
```

### TRON ကိုသုံးရင်

- `CRYPTO_CHAIN=tron`
- Trust Wallet ထဲက **USDT-TRC20 receive address** ကိုသာထည့်ပါ။
- `TRONSCAN_API_KEY` မရှိလည်း စမ်းနိုင်ပေမယ့် production မှာ API key ထည့်ထားတာပိုကောင်းပါတယ်။

### BSC ကိုသုံးရင်

- `CRYPTO_CHAIN=bsc`
- Trust Wallet ထဲက **USDT-BEP20 receive address** ကိုထည့်ပါ။
- `BSCSCAN_API_KEY` လိုအပ်ပါတယ်။

**Seed phrase / private key ကို ဒီ project ထဲ လုံးဝမထည့်ပါနဲ့။ Public receiving address ပဲလိုပါတယ်။**

## ၃။ Customer ငွေပေးချေမှု flow

1. Customer က Billing မှာ Pro သို့ Business ကိုရွေးမယ်။
2. Lingua က `$9.37` လိုမျိုး unique USDT amount တစ်ခုထုတ်ပေးမယ်။
3. Customer က ပြထားတဲ့ network နဲ့ address ကို **တိတိကျကျ amount အတိအကျ** ပို့မယ်။
4. `I have paid — verify now` ကိုနှိပ်မယ်။
5. System က TronScan/BscScan ကနေ incoming USDT transaction ကိုစစ်မယ်။
6. ကိုက်ညီရင် plan ကိုချက်ချင်း activate လုပ်ပြီး `paidUntil = 30 days` သတ်မှတ်မယ်။
7. 30 ရက်ကုန်ရင် translate မလုပ်ခင် Free plan ကို auto ပြန်ပြောင်းမယ်။

Payment စစ်နေချိန်မှာ account ကို **လုံးဝ auto suspend မလုပ်ပါ**။ Fraud အတည်ပြုပြီးမှ Admin က manual suspend လုပ်နိုင်ပါတယ်။

## ၄။ AI Customer Support

Optional:

```env
OPENAI_API_KEY=

OPENAI_MODEL=gpt-4.1-mini
```

API key မထည့်ထားရင်လည်း support widget က keyword-based fallback နဲ့အလုပ်လုပ်နေမယ်။

## ၅။ Admin ထိန်းချုပ်မှု

`/admin` ထဲမှာ:

- User list
- Suspend / Unsuspend
- Crypto payment claims
- Auto verify မတွေ့တဲ့ legitimate payment ကို manual confirm
- Supported apps control

Manual confirm လုပ်လိုက်တာနဲ့ paid plan ကိုချက်ချင်း 30 ရက် activate လုပ်ပါတယ်။

## ၆။ Production မတင်ခင် မဖြစ်မနေစမ်းရန်

- Signup/Login
- Email verify / password reset
- Translation DeepL/Google fallback
- Pro/Business payment claim create
- Exact USDT payment → verify → plan activate
- Transaction hash တစ်ခုကို payment နှစ်ခုမှာ reuse မရကြောင်း
- Payment pending ဖြစ်နေချိန် suspend မဖြစ်ကြောင်း
- Admin manual confirm
- Admin manual suspend / unsuspend
- 30-day expiry → Free plan
- Support bot API key ရှိ/မရှိ နှစ်မျိုးစလုံး

ငွေတကယ်လက်ခံမယ့် production စနစ်ဖြစ်တဲ့အတွက် ပထမဆုံး live launch မတိုင်ခင် **ငွေပမာဏနည်းနည်းနဲ့ test transaction တစ်ခါလုပ်ပြီး address/network/auto verification ကို ကိုယ်တိုင်စစ်ပါ**။
