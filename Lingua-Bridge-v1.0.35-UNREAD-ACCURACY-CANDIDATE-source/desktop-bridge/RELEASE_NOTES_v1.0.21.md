# Lingua Bridge v1.0.21 — Public release candidate

## Added
- Stable Windows app identity compatible with the original Lingua Bridge installation.
- Verified update download button after a newer version is detected.
- Explicit public/private download mode for the website.
- Public Windows installer and ZIP fallback build configs.
- Stable release SHA-256/update-feed publication checklist.

## Preserved
- v1.0.20 Gemini rate-limit stability and pacing.
- Persistent no-refresh messenger switching.
- Pointer reorder and saved account order.
- Burmese/Myanmar and broad-language fallback chain.
- Signal, Chrome/Web, custom apps, device limits, gift codes, and owner diagnostics.

## Security
- Update URLs must be HTTPS.
- Stable update feed requires a valid 64-character SHA-256.
- Silent replacement is disabled until code signing is available.
