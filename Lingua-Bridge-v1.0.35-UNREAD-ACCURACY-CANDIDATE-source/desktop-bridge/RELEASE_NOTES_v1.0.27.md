# Lingua Bridge v1.0.27 — Signal Companion + Escape Back Candidate

## Changes
- Official Signal Desktop companion detection and launch flow.
- First-time Signal linking uses the genuine QR generated by Signal Desktop itself.
- Signal install status can be re-checked from Lingua.
- `Esc` returns from an external link opened inside a messenger webview to the previous messenger page.
- Escape is left to Telegram/WhatsApp/etc. while the webview is still on the messenger host.
- Persistent webviews are retained; no reload/recreate is used for Back.
- v1.0.26 translation speed, auto-detect, no-flash switching, safe-send, unread badges, and account ordering are retained.

## Important Signal limitation
Signal does not provide an official browser chat comparable to Telegram Web or WhatsApp Web. Lingua therefore uses the official Signal Desktop app as a native companion rather than an unofficial embedded Signal web client.
