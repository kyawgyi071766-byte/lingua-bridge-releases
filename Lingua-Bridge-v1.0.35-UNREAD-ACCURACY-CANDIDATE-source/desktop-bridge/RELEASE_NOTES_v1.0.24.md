# Lingua Bridge v1.0.24 Candidate

Focused desktop UX fix only. Existing translation/server/session behavior is retained.

- Account-rail unread badge now mirrors the messenger's actual unread total even when that account is the selected account.
- Selecting an account no longer clears its rail badge while another conversation in that account remains unread.
- Red unread badge is anchored to the service icon, matching the compact account-rail pattern more closely.
- Expanded/compact account rail keeps the bottom collapse/expand and add-account controls.
- Account hover tooltip shows service, saved account name and saved phone number.
- Added Account details action to save account name/phone locally per isolated messenger session.
- Telegram unread selectors broadened for Web K/A/Z layout changes.
- Persistent no-refresh webviews, Gemini/Burmese translation, drag reorder, Signal companion flow, and all v1.0.23 behavior are retained.
