# Lingua Bridge v1.0.13 — Owner Next Steps

This is a side-by-side test candidate. It does not replace stable Lingua Bridge v1.0.9.

## Build on Windows

Double-click:

`BUILD_WINDOWS_v1.0.13_DRAG_LOGO_BURMESE_CANDIDATE.bat`

The builder runs desktop QA, creates the NSIS installer and opens:

`desktop-bridge\release-v1.0.13-drag-logo-burmese-candidate\`

## Test order

1. Install the candidate without uninstalling stable v1.0.9.
2. Add at least three messaging accounts.
3. Hold an account card with the mouse and drag it to the top/bottom.
4. Restart the candidate and confirm the custom order is remembered.
5. Confirm Telegram/WhatsApp remain signed in and active chat behavior is unchanged.
6. Confirm the supplied Lingua logo appears in the app/window/shortcut.
7. Confirm Signal safe launch/fallback still works.
8. Confirm Owner/Admin Custom App Manager still works.

## Myanmar / Burmese incoming display

The candidate exposes Myanmar/Burmese only under **Show incoming customer messages in**.
It deliberately does not add Burmese to outgoing/source selectors.

Real Burmese translation requires:

- Google Cloud Translation configured on the Lingua server, and
- the bundled server source patch (language code `my`) deployed after preview/QA.

The Windows builder does **not** deploy or modify Vercel production. If Google is not configured, the candidate rejects the Burmese selection and keeps the previous language setting.
