# Lingua Bridge v1.0.25 Safe Send + Payment Verification Candidate

## Messenger safe-send fix

The outgoing translation interceptor now cancels every follow-up keypress/beforeinput/click generated by the same user action while a translation is already in progress. This closes the race that could allow WhatsApp Web to send the original draft while Lingua was preparing the translated draft.

The composer is replaced as one full selection and verified before any automatic send. If the messenger editor restores or merges the old text, Lingua stops the send and restores the original instead of risking a duplicate/mixed message. The guard applies to every supported in-app messenger; Telegram's working behavior is preserved.

## Payment receipt safety

Customers can optionally upload a JPG/PNG/WebP receipt (max 5 MB). Lingua hashes the image to detect exact reuse and can use Gemini for visual screening/extraction. The AI result is advisory only.

A paid plan is activated only after an independent blockchain lookup finds the expected inbound USDT transfer. Transaction hashes are unique and cannot be reused across payments. Owner/admin confirmation also performs the blockchain lookup, so a forged screenshot alone cannot activate Pro or Business.

After confirmed payment, Billing refreshes automatically. Customer support reads the signed-in account's real payment state: confirmed paid customers are told to refresh/reload Lingua; pending users are told that payment is not yet confirmed and can contact sshksshk2002@gmail.com with the transaction hash.
