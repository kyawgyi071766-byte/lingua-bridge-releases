# Lingua Bridge v1.0.18.1 — Gemini fallback QA fix

Fixed a validation mismatch in v1.0.18 where runtime code supported `gemini` in `TRANSLATE_CHAIN` but preflight/static QA still allowed only the older DeepL/Microsoft/Google chain.

Current Preview settings:
- `TRANSLATE_PROVIDER=auto`
- `TRANSLATE_CHAIN=deepl,gemini,microsoft,google`
- `GEMINI_TRANSLATE_MODEL=gemini-3.5-flash-lite`

No production deployment is performed by this package.
