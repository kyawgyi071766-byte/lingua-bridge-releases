# Lingua Bridge v1.0.9 Official TRC20 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish Lingua Bridge v1.0.9 through a safe public customer path with owner-only administration and automatic 30-day USDT-TRC20 plan activation.

**Architecture:** The existing Next.js/Vercel service remains the public website, authentication, billing, download gate, translation API, and owner control plane. PostgreSQL/Prisma remains authoritative for users, payment claims, access codes, usage, and expiry. The Windows installer talks only to the server and never contains wallet credentials or provider secrets.

**Tech Stack:** Next.js, TypeScript, Prisma/PostgreSQL, Vercel, Electron, TRON/TronScan USDT verification.

**Spec:** `docs/superpowers/specs/2026-09-22-lingua-v1.0.9-official-trc20.md`

## Global Constraints

- Use only USDT-TRC20 for v1.0.9 production billing.
- Owner address must equal `TC4gLVT6RnjdnMB6qCgq2mAb5KNnM9ovzM`.
- Pro is 9 USDT/30 days and Business is 29 USDT/30 days.
- Never request, store, or deploy a seed phrase or private key.
- Payment verification failure must not alter or suspend an account.
- Admin data and credentials must never be exposed in customer pages, logs, packages, or handoff documents.
- General sales remain closed until one real small-value end-to-end payment passes.

## Review Focus

- A transfer to a different address or token contract must never activate a plan; pin this in Task 2.
- Two customers paying similar amounts must not claim the same transaction; pin this in Task 2.
- An explorer outage must leave the payment pending and the account unchanged; pin this in Task 2.
- A non-owner must not receive admin customer data; pin this in Task 3.
- An unauthorized or stale download link must not expose the installer; pin this in Task 4.
